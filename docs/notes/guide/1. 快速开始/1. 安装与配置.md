> 安装 NcatBot、编写 config.yaml、确认 NapCat 连接 — 运行 Bot 前的必要准备。

---

## 前提条件

- Python ≥ 3.12
- NapCat：首次启动时由 NcatBot 自动安装（Setup 模式），无需手动安装。详见 [NapCat 适配器](<../2. 适配器/1. NapCat QQ.md>)。

::: tip 零基础？
如果你还没有安装 Python，或者不确定环境是否正确，请先阅读 [环境安装指南](<../12. 最佳实践/1. 环境安装.md>)。
:::

## 1. 安装 NcatBot

```bash
pip install ncatbot5
```

或使用 uv：

```bash
uv add ncatbot5
```

验证安装：

```bash
python -c "import ncatbot; print('NcatBot 可用')"
```

## 2. 生成配置文件

推荐使用 CLI 交互式生成 `config.yaml`：

```bash
ncatbot init
```

按提示输入 Bot QQ 号和管理员 QQ 号即可。生成的配置包含 NapCat（QQ）适配器的默认连接参数。

如需启用其他平台适配器，可再次进入适配器管理：

```bash
ncatbot adapter   # 在交互界面中启用并配置 Bilibili / GitHub / Lark 等平台
```

在副屏界面里使用空格切换启用状态，按 Enter 进入当前适配器的配置流程。

::: details 手动编写 config.yaml

```yaml
bot_uin: '你的QQ号'
root: '管理员QQ号'
adapters:
  - type: napcat
    platform: qq
    enabled: true
    config:
      ws_uri: ws://localhost:3001
      ws_token: napcat_ws
plugin:
  load_plugin: true
```

| 字段 | 说明 |
|------|------|
| `bot_uin` | Bot 登录的 QQ 号 |
| `root` | 超级管理员 QQ 号，拥有所有权限 |
| `ws_uri` | NapCat WebSocket 地址 |
| `ws_token` | NapCat WebSocket 认证 Token |
| `load_plugin` | 是否启用插件加载 |

:::

## 3. 确认 NapCat 连接

确保 NapCat 已启动并监听在 `ws_uri` 指定的地址。NcatBot 启动时会自动连接。

连接成功后终端会输出类似：

```text
[INFO] WebSocket 连接已建立: ws://localhost:3001
```
